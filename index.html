為什麼用 Foldspace

把兩台電腦，用一個資料夾接起來

適合自己的桌機和筆電，或辦公室裡每天互丟檔案的兩台固定電腦。

像資料夾一樣用

桌面上的「Foldspace」看起來就是一般資料夾，拖進去就送出，資料夾結構完整保留。

自動找到對方

按「配對…」就會列出同網段開著 Foldspace 的電腦。對方換了 IP，也會用設備指紋自動找回來。

配對一次就好

兩邊顯示同一組 6 位數字，確認後就記住彼此。之後只認對方的設備憑證，別台電腦冒充不了。

預設加密

控制連線一律走 TLS 與雙向憑證；檔案內容預設也加密，需要速度時可以關閉。

不會留下壞檔

每個檔案都驗證雜湊，不符就自動重傳。中途斷線或取消，接收資料夾裡也不會出現半個檔案。

輕巧、原生

單一 exe、免安裝，常駐系統匣。介面用 Windows 原生元件，支援繁體中文、簡體中文與英文。

三個步驟

第一次設定只要一分鐘

  1. 1

    兩台各放一份

    下載 Foldspace.exe，放在兩台電腦上執行。第一次會在桌面建立「Foldspace」，並請你允許防火牆規則。

  2. 2

    配對

    在其中一台按「配對…」，從清單選對方。兩邊確認顯示的 6 位數字相同，就完成了。

  3. 3

    拖放

    把檔案或資料夾拖到桌面的「Foldspace」。收到的檔案會出現在對方的「下載\Foldspace」。

畫面

就是你熟悉的 Windows

設定視窗、配對與傳輸畫面，都用 Windows 內建的元件，跟系統工具一樣好上手。

設計亮點

簡單的外表，認真的內在

Foldspace 只做一件事，所以每個細節都可以做到位。

防中間人的配對碼

配對碼不是只拿兩邊的憑證指紋算出來。發起端先送出亂數的承諾，等對方公開自己的亂數後才揭曉，攻擊者沒辦法事先湊出相同的 6 位數字。

code = SHA-256(fpA ‖ fpB ‖ Na ‖ Nb) → 6 digits

接收資料夾裡只有完整的檔案

檔案先寫進隱藏的暫存區，每個檔案收完就用 XxHash3 比對，不符就在同一條連線重傳一次。全部驗證通過才搬進接收資料夾，並保留修改時間。

為吞吐量設計

檔案分段串流，檔案之間不等回應；小檔案並行讀寫，讀網路和寫磁碟分開進行。傳 5 GB 的檔案時，程式本身占用的記憶體約 100 MB。

只信任配對過的設備

配對後只認對方的憑證指紋，IP 變了也不影響。還沒配對時只接受配對請求，拒絕一切傳輸；防火牆規則只開放同一個子網路。

兩台說不同語言也沒問題

網路上只傳狀態代碼，不傳文字。英文介面的電腦和中文介面的電腦互傳時，各自用自己的語言顯示訊息。

斷線、取消都有交代

每 5 秒心跳，15 秒沒回應就判定離線並自動重連。主動取消顯示「已取消」，斷線或磁碟寫滿顯示「失敗」，不會混在一起。

使用說明

從安裝到傳檔

安裝與第一次啟動
  1. 在兩台電腦各下載一份 Foldspace-<版本>-win-x64.exe，放在你想放的資料夾，直接執行，不需要安裝。
  2. exe 沒有程式碼簽章，Windows 可能顯示「Windows 已保護您的電腦」。按「其他資訊」→「仍要執行」。
  3. 第一次啟動會跳出 UAC。允許後，Foldspace 會在 Windows 防火牆加上規則：只允許同一個子網路的電腦連入，私人與公用網路都適用。
  4. 桌面會出現「Foldspace」捷徑，右下角系統匣會有 Foldspace 圖示，圖示左下角的圓點代表連線狀態。
配對兩台電腦
  1. 在其中一台的設定視窗「一般」分頁按「配對…」。
  2. 清單會列出同網段開著 Foldspace 的電腦，選擇對方。
  3. 兩台會同時跳出配對碼。確認兩邊的 6 位數字相同，各自按「確認」。數字不同請按「拒絕」。
  4. 找不到對方時（不同網段，或訪客 Wi-Fi 擋掉了廣播），到「連線」分頁手動輸入對方的 IP。
傳送與接收
  • 把檔案或資料夾拖到桌面上的「Foldspace」，或拖到設定視窗的「傳送檔案」區。一次要傳很多項目時，建議拖它們的上層資料夾。
  • 傳輸視窗會顯示速度、剩餘時間，可以隨時取消。後拖入的任務會排隊，兩個方向可以同時傳。
  • 收到的檔案預設放在「下載\Foldspace」，完成時會跳出通知，點一下就打開資料夾並選取剛收到的項目。
  • 在「接收」分頁可以設定同名檔案要自動改名、覆蓋或略過，以及接收前要不要先詢問。
看懂連線狀態
已連線：已配對，隨時可以傳檔
尋找中：正在連線或重新連線
未配對：找到對方了，但還沒配對（或配對被對方解除）
離線或錯誤：對方沒有回應、版本不相容、配對金鑰不符等
已停用，或尚未配對任何電腦
常見問題
按「配對…」找不到對方？
搜尋靠區域網路廣播，兩台要在同一個子網路。訪客 Wi-Fi 常會隔離用戶端，這時請在「連線」分頁手動輸入對方 IP。
「測試連線」逾時？
通常是對方沒有執行 Foldspace、服務已停用，或防火牆擋住了。可以在「連線」分頁按「允許 Foldspace 通過 Windows 防火牆…」重新設定規則。
傳大量小檔案很慢？
Windows Defender 會逐一掃描每個新寫入的檔案，一萬個小檔案可能慢上數倍。打包成一個壓縮檔再傳會快很多。
顯示「配對金鑰不符」？
對方重灌系統或刪除過設定，設備憑證變了。請在兩邊解除配對後重新配對。
顯示「版本不相容」？
兩台的 Foldspace 版本差太多，請把兩台都更新到最新版，配對會保留。
解除安裝

從「設定 > 應用程式」，或在開始功能表的「Foldspace」上按右鍵選「解除安裝」。程式、設定、配對資料、日誌、捷徑都會移除，接收資料夾裡的檔案會保留。移除防火牆規則需要系統管理員權限，會跳出 UAC。

確認檔案完整

每個版本都附有 .sha256 檔。在 PowerShell 執行下面的指令，把結果和 .sha256 裡的值比對：

Get-FileHash .\Foldspace-1.0.0-win-x64.exe -Algorithm SHA256

隱私

Foldspace 只把檔案傳到你配對的那台電腦，不連到任何伺服器，不收集、也不回傳任何使用資料。設定、配對資料與日誌都只存在你自己的電腦上。
